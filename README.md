# MindFlow AI

Plataforma web estática para organização de estudos com recursos inspirados em inteligência artificial, acompanhamento de desempenho e preparação para o ENEM.

## Estrutura inicial

- `index.html`: landing page com navbar, hero, benefícios, funcionamento, recursos, bloco ENEM, chamada de cadastro, design system e footer.
- `pages/`: telas de cadastro, login, recuperação de senha, perfil, configurações, dashboard, planejamento, assistente de IA, desempenho, lembretes e conquistas.
- `styles/style.css`: estilos globais, layout responsivo, design system, landing page, área do estudante e componentes de UI.
- `main.js`: interação do menu responsivo, estado visual do header, modal, chat demonstrativo do assistente e feedback de lembretes.
- `docs/`: documentação do projeto, PRD e plano de implantação.

## Fases desenvolvidas

- Fase 1: estrutura HTML, CSS, JavaScript, navbar, footer e página inicial.
- Fase 2: sistema de interface com cores, tipografia, botões, cards, inputs, modal, menu responsivo, ícones e componentes reutilizáveis.
- Fase 3: landing page com hero section, benefícios, como funciona, recursos principais, preparatório ENEM, chamada para cadastro e rodapé completo.
- Fase 4: sistema de usuários com cadastro, login, recuperação de senha, perfil, edição de dados e configurações.
- Fase 5: dashboard com resumo do dia, horas estudadas, metas, progresso, calendário, estatísticas e próximas atividades.
- Fase 6: planejamento inteligente com criação, edição e exclusão visual de cronogramas, organização por matérias, prioridades e metas semanais/mensais.
- Fase 7: assistente de IA com chat, sugestões automáticas, organização dos estudos, recomendações de revisão, dicas de produtividade e orientação personalizada.
- Fase 8: dashboard de desempenho com horas estudadas, evolução semanal/mensal, gráficos, desempenho por matéria, metas concluídas e histórico.
- Fase 9: sistema de lembretes com avisos de estudo, revisões, simulados, notificações e agenda diária.
- Fase 10: sistema de conquistas com medalhas, níveis, XP, streak, recompensas e ranking pessoal.

## Como abrir

Abra o arquivo `index.html` diretamente no navegador.
