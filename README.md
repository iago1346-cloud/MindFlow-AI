# MindFlow AI

Plataforma web estatica para organizacao de estudos com recursos inspirados em inteligencia artificial, acompanhamento de desempenho e preparacao para o ENEM.

## Estrutura inicial

- `index.html`: landing page com navbar, hero, beneficios, funcionamento, recursos, bloco ENEM, chamada de cadastro, design system e footer.
- `pages/`: telas de cadastro, login, recuperacao de senha, perfil, configuracoes, dashboard, planejamento, assistente de IA, desempenho, lembretes, conquistas, ENEM, dicas, contador e contato.
- `styles/style.css`: estilos globais, layout responsivo, design system, landing page, area do estudante, paginas ENEM/dicas/contador/contato e componentes de UI.
- `main.js`: interacao do menu responsivo, estado visual do header, modal, chat demonstrativo do assistente, feedback de lembretes, simulados, dicas, contador ENEM e envio demonstrativo de contato.
- `docs/`: documentacao do projeto, PRD e plano de implantacao.

## Fases desenvolvidas

- Fase 1: estrutura HTML, CSS, JavaScript, navbar, footer e pagina inicial.
- Fase 2: sistema de interface com cores, tipografia, botoes, cards, inputs, modal, menu responsivo, icones e componentes reutilizaveis.
- Fase 3: landing page com hero section, beneficios, como funciona, recursos principais, preparatorio ENEM, chamada para cadastro e rodape completo.
- Fase 4: sistema de usuarios com cadastro, login, recuperacao de senha, perfil, edicao de dados e configuracoes.
- Fase 5: dashboard com resumo do dia, horas estudadas, metas, progresso, calendario, estatisticas e proximas atividades.
- Fase 6: planejamento inteligente com criacao, edicao e exclusao visual de cronogramas, organizacao por materias, prioridades e metas semanais/mensais.
- Fase 7: assistente de IA com chat, sugestoes automaticas, organizacao dos estudos, recomendacoes de revisao, dicas de produtividade e orientacao personalizada.
- Fase 8: dashboard de desempenho com horas estudadas, evolucao semanal/mensal, graficos, desempenho por materia, metas concluidas e historico.
- Fase 9: sistema de lembretes com avisos de estudo, revisoes, simulados, notificacoes e agenda diaria.
- Fase 10: sistema de conquistas com medalhas, niveis, XP, streak, recompensas e ranking pessoal.
- Fase 11: preparatorio ENEM com organizacao por areas, plano de estudos, simulados, banco de questoes, redacao, metas por curso e evolucao.
- Fase 12: dicas inteligentes com dica diaria, sugestoes de revisao, recomendacoes por desempenho e estrategias de estudo.
- Fase 13: contador regressivo ENEM com dias/horas restantes, mensagem motivacional diaria e barra de progresso.
- Fase 14: pagina de contato com formulario, FAQ, informacoes de suporte, links de navegacao e envio demonstrativo de mensagens.

## Como abrir

Abra o arquivo `index.html` diretamente no navegador.
